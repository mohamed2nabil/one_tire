# ADR 006: n8n Integration Security

**Decision:**
Secure all internal APIs designated for n8n with an `x-n8n-api-key` header matching a secure environment variable.

**Context:**
Webhooks and APIs exposed for automation can become attack vectors if left public.

**Alternatives:**
- Relying on obscure URLs (Security by obscurity).
- Implementing full OAuth for the n8n bot.

**Why this approach was selected:**
API keys provide a simple, robust, and easily rotatable security mechanism for server-to-server communication.

**Tradeoffs:**
API keys must be securely distributed and injected into the n8n environment variables.
