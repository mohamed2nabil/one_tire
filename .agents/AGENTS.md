# REFERENCE PROJECT POLICY

The folder "previouse project" is the reference implementation.

Before creating ANY component, hook, utility, service, dashboard page, or layout:

1. Search the current project.
2. Search the "previouse project".
3. Compare implementations.
4. Reuse existing code whenever possible.
5. Refactor instead of rewriting.
6. Never duplicate business logic.

Preserve proven business logic and adapt it to the new branding.
